<objective>
Split the existing single-tier Dockerfile into two reproducible, pinned, fixed-UID images — one JVM-free web tier and one jlink-JRE worker tier — and swap SvelteKit's adapter from `adapter-static` to `adapter-node` so SSR (Gate 4) becomes possible. This plan ships the infrastructure preconditions for Gates 3/4/5: image size can be measured, reproducibility can be asserted, and SSR routes can stream.

Purpose: Deliver a measurable, reproducible, two-tier deployment surface BEFORE Plans 05/06/07 which actually run the measurements. Without this, there is no web image to ship against Gate 5, no worker image to measure for Gate 3, and no SSR surface for Gate 4.

Output:
- `Dockerfile.web` (JVM-free, multi-stage, pinned digests, UID 1001, SOURCE_DATE_EPOCH-aware)
- `Dockerfile.worker` (jlink custom JRE, owlready2, HermiT-ready, pinned digests, UID 1001)
- `.dockerignore` (Gate 5 build-context discipline — excludes `.git`, `output/`, `.planning/`, etc.)
- `railway.toml` (two-service split with distinct healthcheck policies)
- `viewer/svelte.config.js` (adapter-node swap, `precompress: false`)
- `viewer/package.json` (adapter dependency swap)
</objective>
