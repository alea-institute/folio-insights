## Deviations from Plan

**1. `.railway` artifact not created (Railway CLI v4.31 behavior change)**
- **Found during:** Task 1 (link).
- **Issue:** The plan's acceptance expects a local `.railway` file (`ls .railway` succeeds). v4.31 stores link state globally in `~/.railway/config.json` keyed by absolute directory path and creates no local file.
- **Fix:** Functional intent met — `railway status` resolves this dir to project `folio-insights`. Recorded the behavior change in DIAGNOSIS.md.
- **Verification:** `railway status` → `Project: folio-insights / Environment: production / Service: folio-insights`.

**2. Service name is `folio-insights`, not `web`**
- **Found during:** Task 1 (link). First link attempt `-s web` failed (`Service "web" not found`).
- **Fix:** Re-linked with `-s folio-insights`. The "web"/"worker" names existed only in the (ignored) nested toml, never as real Railway services.
