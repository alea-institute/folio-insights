<!-- Valid-time semantics (PRD §21.9) — recap for the walker -->

PRD §21.9: supersession ≠ retraction. Old shard remains queryable. A shard's valid-time interval is [fi:validTimeStart, fi:validTimeEnd). A query "as of date T" returns the shard whose interval contains T. When shard A supersedes shard B, A.fi:validTimeStart == B.fi:validTimeEnd (the SHACL alignment shape enforces this). The supersession chain backward walk: for a given subject S, find the chain of shards via fi:supersedes / fi:supersededBy, pick the one whose [start, end) interval contains T.
