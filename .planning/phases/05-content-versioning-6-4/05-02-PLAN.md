<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller -> edit_shard_content | Untrusted (field_path, new_value, editor_did) cross into the write path; field_path is a dotted attribute selector |
| edit_shard_content -> ShardStore | The store is the persistence seam; in Phase 5 it is an in-memory dict (Phase 13 swaps Oxigraph) |
| get_shard_at -> stored shard | Reconstruction must not corrupt the live stored object |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05 | Tampering | field_path path-injection / arbitrary-attribute-write | mitigate | `IMMUTABLE_FIELD_PATHS` gate (D-06) raises before any mutation for the 10 protected paths incl. triple.subject/.predicate + content_edits/signatures; only declared mutable fields are writable |
| T-05-06 | Tampering | silent wrong-type new_value injection via set_field (validate_assignment OFF) | mitigate | `validate_shard()` post-edit re-validation re-runs full model validation (`model_validate(model_dump())`); RESEARCH Pitfall 2 / V5 input validation |
| T-05-07 | Tampering | get_shard_at corrupting the stored shard | mitigate | `model_copy(deep=True)` isolates the working copy (verified); test asserts store.get(iri) unchanged after the call |
| T-05-08 | Denial of Service | unbounded edit chain during reverse-replay (O(N) undo) | accept | Edit chains are practically bounded (human edit cadence); in-memory store, single-process Phase 5. Phase 13 (persistent store) re-evaluates pagination/bounds. Documented deferred. |
| T-05-09 | Repudiation | sign_attestation placeholder (signature="") | accept | Real ed25519 signing is Phase 6; the stub action="content_edit"/signature="" is unmistakably unsigned (tests assert it). Documented deferred Phase-6 gap. |
| T-05-10 | Spoofing | editor_did unverified | accept | DID verification is Phase 6 (V4 partial). Recorded as the claimed editor only; documented deferred gap. |
| T-05-SC | Tampering | npm/pip/cargo installs | accept | No new packages (RESEARCH Package Legitimacy Audit: all deps pre-existing/pinned). No install task. |
</threat_model>
