| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-02 | Tampering | ContentEdit entry mutation | mitigate | `ContentEdit` frozen=True — any in-place field assignment raises ValidationError (D-08a structural half) |

| T-05-SC | Tampering | npm/pip/cargo installs | accept | No new packages introduced (RESEARCH Package Legitimacy Audit: all 5 deps pre-existing/pinned). No install task in this plan. |
