<objective>
Widen the shard IRI body from hex16 to hex32 (D-01/D-02) and complete the
SHARD-07 canonicalization by adding internal CRLF/CR→LF normalization (D-08),
then prove the full pipeline is deterministic across 1000 random runs (D-09).

Purpose: hex32 (128-bit) makes birthday collisions effectively unreachable
(~1e-29 at 1B shards), turning collision handling into a never-expected
safety-net instead of a runtime concern. CRLF→LF closes the last
canonicalization gap so the same text with differing line endings hashes
identically — the SHARD-07 acceptance criterion.

Output: updated `minting.py` (width + CRLF→LF), widened GlossShard regex in
`subtypes.py`, and an extended determinism test suite (hex32 assertions +
internal-CRLF directed vector).
</objective>
