## Working conventions that held up
- **Worktrees:** one worktree per change under `~/worktrees/`.
- **Implementation:** done by subagents (Codex `codex-run.sh` orphaned and hung once this cycle).
- **Before merge:** an independent adversarial review of every substantive PR, then fixes with failing-first regression tests, then the orchestrator re-runs the suite and the reviewer's probes.
- **Tests from a worktree:** set `FOLIO_INSIGHTS_FOLIO_ENRICH_PATH` to the real folio-enrich backend, use an absolute `PYTHONPATH`, and set `FOLIO_INSIGHTS_CORPUS_ROOT` to a temp dir.
- **Docker:** never run box-wide prunes (one worker did; dangling images were lost).
- **Cockpit:** write a trail receipt per wake submission.
  - **Pending contexts:** a Chief "pending context" is not an answer; file it as a no-op receipt.
