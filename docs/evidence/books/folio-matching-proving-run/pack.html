Bottom line · v7 fix landed · acceptance bar met

The v6 precision regression is fixed. v7 kills the place / agency / Slovenia failure classes while preserving the recoveries — on identical source, for $0.17.

The v6 root cause was engineering, not modeling: label→IRI resolution dropped the concept’s branch (so the place/agency gates never saw a tag) and accepted the top match at ≥0.6 on a 0–100 scale (a no-op bar), so generic terms latched onto the short place/agency labels rapidfuzz over-scores to exactly 90.0. v7 fixes both in the shared folio_matching resolver — decompose-first for compound headings, a calibrated 92.0 bar, and a branch on every resolved tag — then lets the deterministic gates and the real-IRI blocklist veto what remains.

Result (v6→v7, same harness): non-heading place mis-maps 739 → 0 agency homonyms 150 → 1 Slovenia units 168 → 0 — all at or below the pre-pin v5 baseline — while the named recoveries survive (Burden of Proof 55, Hearing 21, Lawyer 47) and the metadata unit is now excluded. Proposed-class rises to 1605 (2.33/unit) because v7 correctly declines to force-resolve the 889 mis-maps v6 invented; per unit that is below v5’s 2.68. The folio-enrich migration hold can lift.
