Bottom line · reviewer decision requested

The plumbing is proven; the gates aren’t catching the real failures — and the run surfaced a new precision regression.

The pinned package integrates cleanly: the reconciler seam runs on folio_matching, the entity-ruler path was restored, and decomposition is wired and unit-tested. But on this chapter the pin trades one failure for another. It eliminates every “no map” entry (proposed-class-only 1244 → 0) — recovering the correct maps you asked for — yet it does so by force-resolving generic terms, which floods the output with wrong place-name and agency homonyms (non-heading place mis-maps 1 → 572). The three headline failures you flagged — Slovenia, Action, metadata — are not fixed.

Recommendation: hold the folio-enrich migration until the gates (place / short-label), calibration, and the domain prior are wired into the label-resolution path, and the resolution threshold is tightened. Detail and per-finding sign-off below.

The regression, concretely

The pin’s aggressive whole-string label→IRI resolution (accept top match at score ≥ 0.6) recovers real maps — but with no gate able to see it, it also snaps generic legal words onto plausible-looking country / state / agency concepts. Sampled from v6:

  • law → Delaware
  • Presumptions → Northern Mariana Islands
  • Decision Maker → Slovenia
  • effect of answers → Federal Election Commission
  • Verdict Forms → Venezuela
  • closing statements → Collateralized Loan Obligation
  • Jury charge → Argentina

Correct recoveries (also new in v6)

  • Burden of Proof → Litigation Burdens of Proof your finding-005 example
  • Hearing → Hearing
  • Lawyer → Lawyer
  • Closing Arguments → Closing Arguments / Summation
  • narrative → Matter Narrative
Root cause — resolved tags carry an empty branch, so the place-name / short-label gates (which key on branch) can’t identify them; and high LLM confidence (≥0.85) exempts them anyway. The gates run, but the homonyms are invisible to them.

What was wired vs. not

  • wired
    Reconciler seam — the 2-path base now runs on folio_matching.Reconciler; no folio-enrich checkout needed for reconciliation.
  • wired
    entity_ruler — I repaired a broken import (folio-enrich moved the module, silently zeroing the ruler path) by wiring the pinned FOLIOEntityRuler. 68,693 patterns; restored ~1000→1705 ruler tags. Also advances the migration.
  • wired
    decompose — I wired & unit-tested conjunction-split into label resolution. Correct, but rarely fires on Ch02 (whole-string resolution short-circuits it).
  • wired · no-op
    alias blocklist — on, but the seed is synthetic, so it matches nothing in real data.
  • wired · misses
    place / short-label gates — on, but exempt heading_context (the actual Slovenia vector) and can’t see resolved tags (empty branch). Net effect on Ch02: negligible.
  • not wired
    SourceClassifier (metadata exclusion), DomainPrior (context-aware disambiguation), ScoreCalibration (weak-band), Judge — all present in folio-matching, none in the tagger path. These are exactly what the regression needs.
